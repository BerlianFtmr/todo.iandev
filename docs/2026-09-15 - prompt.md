# Memperbaiki error di add folder

kondisi :
aplikasi ini saat aku check menggunakan `npm run dev` berjalan dengan baik seperti yang di inginkan, namun berbeda saat aku menjalankan menggunakan `docker compose -f docker-compose.prod.yml up -d --build`

masalah :
ketika aku menjalankan menggunakan `docker compose -f docker-compose.prod.yml up -d --build` maka nanti ketika aku add folder akan muncul error dengan log `Unknown column 'parent_id' in 'field list'`
