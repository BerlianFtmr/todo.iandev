# Menghubungkan frontend ke backend

kondisi :
saat ini aplikasi sudah bisa di akses menggunakan `npm run dev` namun data yang terisi masih bersifat temporary ketika website direfresh atau dibuka ulang datanya akan hilang. aku sudah membangun database MYSQL menggunakan docker dan backend menggunakan express.js

diskusi :
coba analisis bagaimana penerapan agar frontend dapat terhubung ke backend dan database, mari kita diskusikan kondisi sekarang dan penerapan skema terbarunya untuk integrasi tersebut.
